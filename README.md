# KindergartenChinese

A playful kindergarten Chinese writing app built from `ChineseStrokeLearningApp`.

The rewrite keeps the real Hanzi Writer stroke-order practice and CUHK Jyutping audio proxy, then reshapes the experience into three kid-friendly screens inspired by the reference image:

- Bamboo-framed home screen
- Island learning journey
- Parchment writing practice board with pinyin, audio, stars, retry, demo, and next controls

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
